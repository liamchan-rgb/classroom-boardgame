# 侧视战斗场景实验 · v0.11

本版把已确认的右向侧视接触姿势放进此前的 iPad 桌游 App，试验战斗面板改为横向舞台的构图。战斗场景仍留在原来的地图与回合界面中；地图、行动队列、技能物品栏和生命/护盾数据照常显示。

## 当前实验内容

- 舞台背景由天空、远山、林线、遗迹剪影和地面组成，作为分层 2D 场景测试。
- 左侧固定展示用户确认的 `heavyStrike + trainingSword` 右向接触姿势，作为与当前行动者分离的冒险者动作样片；右侧读取本局当前地点已经公开的真实敌人素材。行动者姓名、生命、护盾、存活/倒地和下轮状态仍来自原战斗快照。
- 姿势明确标为“动作姿态样片 · 单帧”。它是静态构图参考，不播放慢动作，也没有补造攻击起手、挥砍过程或命中结算。接触姿势不替代玩家当前职业原立绘资源。
- 游戏规则、伤害、骰子、技能触发、敌人选择、存档格式没有改动；镜头层只读当前公共战斗状态。

## 安装与实验

本版 App 为 0.11（构建 11），Bundle ID 延续 `org.personal.classroom.stage0`，产物是未签名 arm64 iPad IPA，需通过 SideStore 使用自己的签名安装。安装后创建/恢复一局并进入实际战斗，即可在屏幕右侧看到侧视舞台；观察人物与敌方大小关系、剑尖到敌方的距离、暗背景在 iPad 横屏的辨识度，以及战斗 roster / 回合队列是否仍易读。

## 尚未完成

这只是场景构图实验：目前人物接触姿势保持静止，现有敌方素材并非全部侧面设计；攻击起手、蓄力、挥砍、受击、倒地、回合空闲姿态、目标锚点、命中特效时序与方向都没有完成。下一步应先在 iPad 上确认镜头和空间构图，再制定统一像素密度/角色脚底锚点并制作攻击关键帧，最后把动作与已经提交的战斗结果一一对应。当前设备效果未实测时，不把云端模拟器截图作为真机验收。
