# 课堂桌游 v0.8：快速开始

用SideStore和同一Apple ID覆盖安装新版IPA；保留现有App。安装名仍为ClassroomProbe。

1. 主页面点“进入PVE课堂”。可使用已准备的森林地图，或“教师操作 → 创建新局”设置1—6学生与可选主持人、姓名和职业。
2. 探索选择左侧玩家，右侧选择“移动”，按相连道路依次点地点，检查路径费用，再点“确认执行”。遇到第一个敌人处自动停止并开战；其他角色原位置入队。
3. 若是手动暂停，点“继续（空格）”。当前角色可以移动、普攻、技能、道具或救援；先选目标再确认。怪物按固定队列自动行动；“结束回合（E）”保留行动点。
4. 奖励对象单独勾选。G金币＋10、A行动点＋1、S积分＋2；多人各获得完整一份。1—6选择学生，7选择实际存在的主持人；Shift＋数字多选奖励。
5. 需要药水或复活石时，选奖励对象后点“发练习补给”。救援需同地点、2AP和个人1复活石，恢复半生命向上取整，战斗中下一轮才能行动。
6. “教师操作 → 调整资源/教师复活”可调整当前生命、护盾、AP、金币和积分；面板自动暂停。全员倒地后由教师复活、调整或结束本场，不自动扣资产。
7. “绘本”暂停PVE并保留当前状态。可加载测试PPTX/导入文件，左右方向键翻页，备注仅在教师端；返回游戏保留其他暂停原因。电视的绘本状态条不显示AP。
8. 每次完整操作自动保存。重新启动/本机恢复后保持暂停；菜单里可查看最近30步、撤销完整一步、延长15秒、手动保存与恢复。

## 两个验证剧本

“教师操作 → 创建新局”选择明确标注“验证”的剧本。

- **龙骑士自然20群攻**：首位角色龙骑士，生命5/32。移动到路口，轮到该角色后用龙焰对路口。一次自然20击败史莱姆、弓手和巨魔，自疗至11、护盾6、积分7；全部掉落与附带效果完成后回探索。
- **魔龙群体倒地**：至少2个玩家，已位于路口。点当前位置开战并继续，魔龙先行动，龙焰自然20令全体玩家倒地并暂停。用教师操作复活、调整或结束。

公开电视应显示地图/骰子/玩家状态，不出现教师按钮、备注或未探索内容。新键盘、后台/断连重连与电视排版请在本设备核对；完整PPTX排版仍保留已说明的限制。

正式美术、商店/交易、完整随机地图编辑、自定义快捷键和正式存档包会按后续阶段接入。
