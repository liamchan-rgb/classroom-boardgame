# 不等待新美术的地图与战斗显示改造 · v0.10

继续最新main与v0.9现有66张本地素材；本轮独立推进地图镜头、人物定位、探索/战斗阶段布局、连续回合轨道、技能/物品展示。新美术交付后再按manifest ID替换地图角色/动作和场景层，不回退程序、不覆盖旧设计稿。现在沿用已有独立人物图片，移动为沿已提交道路的平移；尚未交付自然走路肢体帧或八方旅人式完整战斗新美术，不能把结构版当最终审美通过。

## 已实现方向

- 地图按真实节点/道路位置显示角色，同节点按稳定unitID错位；玩家在视野外时用头像和方向箭头表示，避免重叠。
- 教师点击地图/边缘玩家头像或镜头菜单明确查看该玩家；总览、跟随、缩放、拖动/方向按钮只改变公开镜头，不选行动者、不更改奖励或费用。公开电视只读同步，未知节点/敌人/道路仍从原公开投影隔离。
- 探索移除右侧战斗区和战斗轨道，扩大地图；已提交移动从实际到达路径读取，到达后展开右侧战斗区。动画不重掷骰、不额外扣费、不中途补结算，恢复不补播。
- 连续混合回合轨道以连线、已行动段和当前指针表示，完整队列不重排；头像稳定ID标记、倒地叉、已行动勾、救援后下轮时钟，底部不重复姓名。
- 当前玩家独立技能/物品栏读取实际本局定义、次数、数量和可用性；费用/限制与不可用原因可见。物品4项/页，教师镜头菜单翻页；装备仅只读说明战斗不可换装，不提前开发经济界面。
- 怪物回合收起玩家技能/物品栏，公开资源状态无AP；绘本仍完整等比页面与7人姓名/六字段。原键盘、奖励多选、暂停原因和剩余时间保留。

## 验证与边界

新增核心检查覆盖镜头坐标/边缘聚合、实际遇敌截断路径与多人移动、一次播放/恢复抑制、真实技能物品可用性和私有选择隔离。云端原生截图扩展为20张，包含两比例探索/玩家/怪物/绘本、离屏角色、18物品分页、到达前后与教师屏。构建/检查结果随后记录在evidence，未取得本版真机反馈。
