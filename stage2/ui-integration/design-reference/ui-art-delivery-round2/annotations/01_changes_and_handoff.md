# 修改说明与原生交接

## 教师端
维持1366×1024逻辑点的已通过布局。系统字体、等宽数字；执行按钮56pt，常规触区至少44pt。画面中的技能费用、次数、目标条件仅为原演示数据，正式由本局模板与规则状态读取。没有变更职业或技能定义。

## 公开战斗
两比例关键安全区仍为5%。展开时：16:9地图宽760、右侧944；4:3地图596、右侧676，间隔24。y228、高552。收起时地图占据安全区全宽。七人状态条y800、高186，图例到y1026内。

仅有战斗时展开右区，状态由游戏阶段控制，不由播放或UI点击决定。右侧静态人物表现是在当前节点上的放大呈现，不是逻辑移动、独立战斗地图或传送。当前只展示最近一次已提交技能强击；下一步技能选择、合法目标和可用性只能在教师端操作。公开技能区的更多内容需基于已允许公开的结果字段，不能读取教师私有选择或后台模型。

节点布局重排保持ID与道路关系；原地图的道路距离、AP费用与射程不变。未知节点只有问号，无底图/头像/装饰提示。收起稿沿用公开单位演示数据，仅检查布局，可见敌人不表示一定处于真实探索状态。

## 七人状态区
名称28、资源26、辅助24。16:9七列等宽；4:3两条长姓名使用222宽，其余五列170.4宽。全部角色固定可见，不滚动或截断姓名，不将缩写写回存档。长英文按展示断点换行，全名24字符保持不变；中文12字符完整。

队伍采用颜色+矢量形状，圆/菱形/三角与蓝/橙/紫队名对应，等同于用户要求的颜色或emoji分类，但避免emoji跨设备字体差异。新队伍必须有名称与非颜色区分，不限定三队。主持人和倒地标记独立显示。姓名与资源不烘焙到独立头像。

## 绘本
同一条七人状态区保留姓名、生命/最大生命、护盾、金币、积分、队伍；不含AP。绘本区域使用aspectFit完整容纳，占位页16:9。实际PPTX可有其他比例，不能裁切正文或强制改成16:9。

计时未启用时没有计时UI；启用时在安全区单独显示暂停剩余17秒，页面上边距为94，避免遮挡。隐藏计时不等于解除暂停或清零；手动暂停打开绘本/历史再返回，仍保留手动暂停和剩余时间。

## 材质、动效、素材
大面板目标系统毛玻璃，主要执行按钮实色湖蓝，小控件可系统液态玻璃或纯色；静态预览不能证明真实模糊。文字衬底稳定，低对比背景只作装饰。减少透明度时采用实色；减少动态效果时立即显示同一结果。

沿用B冒险者与史莱姆原样稿；其他未制作职业/怪物仍占位。后续人物动画须只读已提交结果，不重新掷骰或结算，不影响决策时间。救援、自疗、护盾、掉落、积分、自然20与战斗结束全部保持一次实际提交。原费用、规则与数值来源不变。
