## 本轮修改

- 教师战斗：保留已通过的三栏布局、44pt触区与56pt执行按钮，统一B配色；行动中与教师奖励勾选继续分离。
- 公开战斗：右侧增加静态战斗表现与只读已执行技能；地图在展开时变窄。另有收起状态稿。节点/道路与单位位置不因战斗表现改变。
- 公开玩家卡：改为七人单条区域，颜色配圆/菱形/三角标识队伍，附实际队名对应表；战斗保留AP，绘本不含AP。姓名28、资源26、必要辅助24保持原尺寸。
- 绘本：其余空间优先给等比完整页面；未启用计时稿完全不显示计时器；另交启用计时的暂停17秒变体，计时区域不覆盖页面。
- 组件、结算/隐私、密度说明板：信息语义保持已通过状态，统一B配色与既有B样稿。密度说明板仍使用完整队名便于核对，不是公开端常驻玩家卡。

## 检查和限制

已检查PNG尺寸、浏览器实际字形墨迹边界与文字相交、公开5%安全区、七人完整姓名、绘本无AP、字体/资源离线、两公开比例、保留素材哈希及ZIP逐文件校验。SVG getBBox包含字体全局上下空间；报告同时保留getBBox与Canvas实际墨迹测量，以后者判断文字相交，再目视核对。

毛玻璃仍是渐变/浅色的静态材质近似；原生Material、液态玻璃、降低透明度、触控效率、电视远距离可读性、双画面运行隐私、暂停切换和动画均待开发/真机验证。没有实际PPTX，绘本只用占位页。收起状态稿是布局示意，沿用已揭示单位的密度演示数据，不是规则运行结果或探索存档。

本轮只写独立设计分支的design目录，不改App、GameCore、main或工作流，不构建IPA。原第一轮文件、ZIP、标签不变。恢复与后续上传要求见annotations。
