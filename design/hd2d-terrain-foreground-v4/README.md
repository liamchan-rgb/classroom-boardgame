# HD-2D 场景结构与前景修正 v4

v3角落树在缩放触发避让条件时直接消失，而且没有参与地图统一光照。v4改为独立树、稳定视口尺寸、连续0.34—0.90透明度避让与共同材质光照；关闭景深只关闭模糊。缩放保持已拖动的镜头中心。

新场景使用独立树的自然林带、缓坡法线、岩壁/土坡、营地地面过渡与较短低透明度投影；新角色图集统一尺度，P1/P3到站后保留清楚间距，塔旗高度适配总览。iPad默认4:3，同时保留16:9和全部效果开关。原图集、理想参考、旧稿和旧版本保留，正式App/规则不改。
