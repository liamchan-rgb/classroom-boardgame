## 静态实体资源

4职业、6怪物、18装备道具均有独立透明PNG。冒险者和史莱姆保持原B样稿字节；新增3职业、5怪物和18物品。人物/怪物1024×1024、物品512×512，RGBA/sRGB，透明留边至少10%。已按原GameCore目录ID逐项核对，runtime不依赖数组顺序。

新造型基于原B冒险者/史莱姆参考，由image_gen原创制作，原生成图片和总览草稿全部保存。总览图不作为App整页背景。独立头像无姓名、资源数字、队伍或卡框；物品无文字、价格、数量。职业图中的弓/剑/盾是职业象征，不改开局训练短剑、装备通用或技能规则。

装备道具严格为原18ID：12普通物品、星辉3件和龙之3件；没有增加新职业、怪物、装备或属性。6个UI资源图标沿用原原创SVG/PNG。节点和正式地图装饰仍planned，不能误称完成地图插画。

`asset-manifest.json`记录ID、路径、尺寸、透明性、SHA256、生成来源和状态。制作完成表示文件齐备，**不等于用户已逐图通过最终审美**。新素材标为production-candidate-awaiting-art-review，沿用样稿明确区分。

## 动画

基础动画批已制作：覆盖10职业/怪物的6状态（待机/移动/出击/受击/倒地/救援）参数，及12套每套8帧的独立透明表现贴图（2048×256，单格256）。不是逐帧肢体/骨骼或全方向行走，不修改规则状态、不重复结算。原生接入与真机效果由开发对话验证。

## 文件与恢复

assets/classes、monsters、items为独立运行PNG；sources有完整生成原图、总览、可编辑标准导出SVG和脚本。previews为总览，不强制用户继续审核。透明PNG以Chromium/sRGB标准画布机械导出，未手工重绘；物品按总览独立连通轮廓生成SVG选择裁切，保留原颜色与alpha，防止邻图串入。

重建需Python3/Pillow/numpy/scipy（只读alpha分析）、Node/playwright、Chromium；这些不是App运行依赖。原素材来源依OpenAI服务适用条款，不引用第三方游戏资产、不声明独占权；原创SVG/动效几何可随本项目使用。没有在线字体/资源依赖。

每批独立ZIP、标签与回读回执见design/ARCHIVE_INDEX.md；旧图、旧ZIP、旧标签保留。尚未真机验证原生玻璃、素材采样、观看距离、动画或App规则；没有实际PPTX。
