## 本轮变化

- 战斗人物下方改为生命条，长度=currentHealth/maximumHealth；不用一排生命/护盾数字盒。准确生命值可悬停人物查看，并提供无障碍读数；实际倒地保持空条和×。非零护盾需显示独立小标记，当前全零示例不重复写“0”。
- “新动力”按行动力/原AP理解：当前行动者在下方用黄色菱形，剩余填黄、已消耗槽fill=none。本例1/8；8是该布局fixture的本局AP上限，不是新增容量规则。不新增货币，不改费用或补点。
- 顶部玩家字段只留全名；回合/暂停/计时仍为独立游戏信息。金币、积分、队伍和当前行动力合并到底栏一次。生命已在战斗阵位，底栏不再复制一条；零护盾不复制。底部不重复姓名。
- 技能默认只显示名称；物品只显示图标、名称和持有数量。原费用、射程、目标、效果、余次、可用性/原因在查看时完整展开，未删掉规则信息。
- 详情放在地图下方空白区；不遮人物、节点名称、战斗HUD和完整混合轨道。收起时不占详情高度。主地图/战斗由480px增至600px，底栏由248px降至128px。

这是对旧“公开战斗状态无AP”的**最新用户显示意见覆盖**；绘本与其他状态不在本次修改范围，仍按原要求。只在显示层表现原AP，不更改任何GameCore或存档。
