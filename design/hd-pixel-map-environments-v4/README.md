## 接入/尺寸/动画注解

稳定资源ID为map_environment_snow、map_environment_volcano，文件/尺寸/SHA见asset-manifest.json。环境是装饰，不对应新增节点或玩法；雪不减速、冰晶不发奖、岩浆不造成伤害、石崖不改变道路或射程。不得依据插画新增障碍/传送/奖励，也不能把远处建筑当作已揭示节点。程序按原真实nodeID/坐标/公开道路叠加，未知节点仍使用原未知资源。

图内已有近中远景与光照，但尚未拆独立透明层，不能单独做视差或关闭烘焙光照。当前可用作单张环境底图；更大世界扩展需另做可拼接地面与分层景物，不能假称本图无缝平铺或完整地图资源集。

像素主体用nearest采样，等比缩放；HUD仍是原生毛玻璃/液态玻璃组件。雪地浅背景上的道路与单位建议增加冷深色描边/阴影；火山暖色背景的血条与AP保留独立描边，避免仅用颜色区分。

本轮为静态资源，无动画帧。后续若加雪粒/灰烬或热光，需独立显示层、稀疏低强度，避免遮住角色与节点；减少动态关闭粒子/视差，直接静态终态。不新增震屏、伤害提示或规则调用。两比例实际人物合成与真机阅读仍待接入后核对。

素材完整读取和预览输出检查见evidence.json。仅新增design目录，不改App/规则；恢复存档见ARCHIVE_INDEX.md。
