# 设计验收清单与证据范围

本轮为可交接的静态设计，演示数据在 `sources/demo-scenarios.json`。这些案例不运行规则计算；设计稿通过不等于App、真机、规则或复杂PPTX验收通过。首次验收在设计源与导出预览核对，正式接入后在2021款12.9寸iPad Pro/iPadOS27与教师实际无线电视上复核。

## 1. 本轮交付与静态审阅

| 项目 | 静态判定方式 | 交接范围 |
|---|---|---|
| 两种相近方向 | A晨光森林/B晴空学园，各有少量角色/怪物样稿 | 视觉提案，尚未确定批量定稿方向 |
| Teacher1366×1024 | 对照布局尺寸、2倍PNG、组件与独立源 | 常用操作可一屏到达，触区>=44 |
| 公开1920×1080 | 关键内容在96/54安全区内 | 主要文案>=26；姓名/资源可读 |
| 公开1440×1080 | 重排地图、结果与7角色，不能水平拉伸 | 主要文案>=26、长名28两行 |
| 7角色+3怪物 | 6学生+主持人；史莱姆甲/乙与狼；固定10单位队列 | 所有人保留，不用抽样4人替代 |
| 长名字 | 12汉字与24英文字符边界实际排版 | 英名明确换行，Teacher完整可查看 |
| 行动者与奖励对象 | p_a行动中；p_b/p_c选奖，分别标记 | 公开无奖励勾选，奖励选择不换回合 |
| 资源与队伍 | 生命/最大、盾、AP、金币、积分、队伍独立 | 公开战斗保留AP；倒地阿乐保留金币/积分 |
| 组件状态板 | 卡、按钮、节点、队列、计时、结果对应本文档 | 状态用文字/图标，不只颜色 |
| 少量独立素材 | PNG透明、sRGB、主体留边、按已有ID清单 | 未制作资产写待制作；不虚报全套4/6完成 |
| 离线交接 | ZIP含源、预览、令牌、清单、注释、独立素材 | 不依赖在线字体或图片服务 |

静态布局按实际字形与边界测量，特别检查底卡两行長名、英文连续字符串；超长队伍名仍需接入后测试，不能只验证SVG viewBox尺寸。对比度对实际文字衬底计算，普通文本>=4.5:1、大字>=3:1。真实毛玻璃背景变化、液态玻璃与电视亮度待原生/真机复核。

## 3. 核对自然20、奖励与救援的数据一致性

主战斗预览的强击为D6=4+2=6，史莱姆甲生命8→2；没有击杀分与掉落。当前选强击目标为尚满血的史莱姆乙，界面只是选择，不能把选择状态误标成又已提交一次攻击。

独立自然20案例为龙骑士对史莱姆、石像守卫、遗迹魔龙，普通1+普通1+Boss5=积分+7；已固定金币掉落5+30=35与药水/复活石各1。生命26→32实际自疗6，盾4→6实际+2；最后敌人全战败，临时战斗增益结束后归0。数据没有任何随机采样或概率推算。

救援案例最大生命13是本局可编辑状态的示例，不改冒险者初始12模板。成功恢复7，当轮不能行动，下轮资格保持原队列；缺同队/同节点/AP/石任意一项均不可执行。

## 4. 后续批次与待真机项

风格选择后才批量制作4职业与6怪物；18物品和地图装饰按阶段3/4推进。未指定学生年龄，当前采用明亮、不过度幼龄化的轻奇幻；不加入新角色职业、魔法值、技能冷却或成长系统。

待开发/真机检查：原生Material与插画的动态对比度、液态玻璃小控件表现、降低透明度/动态效果、最远座位阅读、系统安全区域、实体键盘与文本输入隔离、外屏断连重连、完整暂停/回退/存档、复杂本地PPTX。此轮不重写v0.7或阶段1验收为已通过这些新项。

每轮设计存档保留本轮版本、预览、源、独立素材、令牌、清单与说明；资料库归档成功与否以工具回执为证，交接ZIP本身不是已经存入ChatGPT资料库的证明。
