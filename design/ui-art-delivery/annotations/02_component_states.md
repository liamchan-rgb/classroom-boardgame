# 组件状态与材质标注

本文件描述两个方向共用的组件语义。颜色、尺寸与字体的机器可读值见根目录 `design-tokens.json`；本文件提供状态组合与文案，不另建一套令牌。所有运行数值来自 App。

## 1. 大面板与小控件

顶部、地图容器、角色栏、操作栏、结果栏、底部奖励栏使用 iOS 原生 Material 毛玻璃；在插画上提供足够亮的稳定衬底。PNG/SVG 预览仅表现材质关系，真实模糊由 SwiftUI 实现，不能把预览底色当完整原生效果。

小型次操作按钮、页码和中性徽章允许液态玻璃，生命/AP等密集数字区采用实色衬底；主要执行按钮采用实色主操作色配高对比文字。避免在阅读数字的底层安排高反差树枝、粒子或运动。打开「降低透明度」时切实色面板；「增强对比度」时增加描边/实色文字衬底。

| 基础属性 | 教师端 | 公开端 |
|---|---|---|
| 常规正文 | 17–20 pt | 26–32 设计单位 |
| 辅助说明 | 最低15 pt | 本轮必要文案最低26 |
| 长姓名 | 最多2行，每行17 pt | 最多2行，每行28；正常姓名28–34 |
| 标题 | 24–30 pt | 40–48；行动者/倒计时48–64 |
| 字体 | iPad系统中文/英文、系统回退 | 同左；不使用像素字体显示正文 |
| 数字 | 等宽数字、独立文字层 | 等宽数字、独立文字层 |
| 触摸 | 至少44×44 pt，主要动作高52–56 | 无教师操作入口 |
| 间距/圆角 | 8/12/16/24/32；面板16、按钮12 | 由布局比例与可读性令牌调整，不直接整体缩小 |

预览字体仅作跨平台排版替身；App使用系统字体，不应把预览字体文件当成运行依赖。

## 2. 角色与怪物卡

| 状态 | 可见样式 | 文字/标记 | 交互与叠加 |
|---|---|---|---|
| 普通 | 毛玻璃/浅实色卡，稳定边框 | 姓名、资源、队伍 | 点详情不执行规则 |
| 当前行动 | 主色粗边 + 左侧行动标记 | 「行动中」 | 不代替奖励勾选 |
| 奖励选中 | 教师专属勾选框 + 奖励色小边框 | 「奖励对象」及底栏名单 | 可多选；公开不显示勾选 |
| 合法目标 | 椭圆/十字目标记号 + 描边 | 「可选目标」 | 教师选择后等待明确执行；公开不展示未提交意图 |
| 受击 | 短闪色/小位移，数字始终清晰 | 实际「生命−…」「盾−…」 | 300–450ms反馈；重放不重算 |
| 倒地/战败 | 低饱和头像、倒地姿态/斜向小标 | 玩家「倒地」；怪物「战败」 | 生命0、盾0；保留金币/积分；奖励可继续 |
| 主持人 | 中性主持人标记 | 「主持人」 | 不用队伍颜色暗示另一个阵营 |
| 新加入/救援后 | 小时钟轮次标 + 中性边 | 「第…轮可行动」 | 队列位置不丢；当轮不可行动 |

叠加顺序：普通基础 → 主持人/队伍 → 倒地或下轮资格 → 行动中 → 目标 → 教师奖励勾选。状态区域与姓名错开，不能把所有状态都堆在头像上；当前行动和奖励同人时两个独立标记同时保留。倒地者不会合法成为普通治疗对象，救援标记使用专属目标状态。

同职业不同角色使用同一模板头像，姓名、队伍、角色序号与边框区分；独立 PNG 不含姓名、队伍或资源。没有已定稿头像时使用统一职业/怪物轮廓占位，不用冒险者样稿假装所有职业已制作。

## 3. 资源组件

| 资源 | 图形与语义 | 标签与数字 | 状态 |
|---|---|---|---|
| 生命 | 心形/生命条、生命语义色 | 「生命 当前/最大」 | 满、受伤、临界、倒地；数字保留 |
| 护盾 | 盾形、护盾色；与生命分区 | 「盾 …」 | 0也保留字段；取较高值；倒地归0 |
| 行动点 | 行动符号、AP色 | 「AP …」教师可附上限 | 0、充足、不足、触顶；公开战斗有，公开绘本无 |
| 金币 | 硬币、金币色 | 「金币 …」 | 已提交增加/减少，不用币图标代替字段 |
| 积分 | 星/奖记、积分色 | 「积分 …」 | 可为负；与金币分开 |
| 队伍 | 名称 + 非颜色标记 + 队伍色 | 「蓝队」「橙队」等实际名称 | 可变数量；颜色不是唯一信息 |

生命条只有视觉比例，数值仍读状态；护盾不能叠画成生命延长段。动画跳字用已提交的 before/after 差额。触顶 AP 奖励示意「请求+2，实际+1，已达上限」；公开可显示「AP+1」，教师看请求与实际全部信息。不要显示「+2」后悄悄截断数字。

## 4. 动作、技能与道具按钮

| 状态 | 文案结构 | 样式 | 是否执行 |
|---|---|---|---|
| 可用 | 名称 / AP费用 / 射程 / 次数 | 实色或稳定玻璃衬底，高对比 | 先进入选择；自体技能亦明确执行 |
| 选中 | 「已选：…」 + 同一费用信息 | 描边 + 勾/动作标记 | 不扣费、不掷骰 |
| AP不足 | 「需要…AP，当前…」 | 不可执行 + 明确文字原因 | 否 |
| 次数耗尽 | 「本场次数已用完」 | 次数0 + 禁止记号 | 否 |
| 无合法目标 | 「无合法目标」或具体「距离不足」 | 保留文字与图标，不只变透明 | 否 |
| 未选目标 | 「请选择合法目标」 | 执行按钮不可用，选择按钮可用 | 否 |
| 阶段不允许 | 「仅战斗可用」等来源于模板 | 禁止记号 + 原因 | 否 |
| 救援缺条件 | 「需同节点倒地队友 / AP2 / 复活石1」 | 缺项就地标注 | 否 |
| 执行中 | 「正在结算…」 | 防重复提交，不重置视觉对象 | 仅已请求一次 |

教师右栏保留移动、普攻、三个职业技能、道具、救援、结束回合的入口。动作选择与执行为不同事件；常规攻击/发奖不用额外确认框。详情、背包、扩展套装技能可在右栏内部滚动，但主要执行/取消与结束回合固定可达。

## 5. 节点、道路与拥挤位置

| 状态 | 视觉与中文 |
|---|---|
| 已探索 | 中性节点形、真实地点名与已公开类型 |
| 未知轮廓 | 虚线轮廓 + 问号 +「未探索」；不露Boss/奖励图形 |
| 当前地点 | 外环 +「当前位置」或行动者焦点 |
| 路径经过 | 教师临时描边路段 + 方向/总费用；公开仅已提交移动路径 |
| 已公开敌人 | 敌方轮廓/真实实例 +「敌方」；不把敌人颜色当队伍 |
| 奖励已领 | 完成标记 +「已领取」；不能因重新进入播放新金币 |
| 同地点多人/多怪物 | 数量徽章 + 分组气泡；Teacher可展开名单；公开已知数量 |

节点与道路须独立于背景，以可编辑源或原生图形绘制。教师节点触区至少44pt；拥挤时移动人物标记或展开浮层，不移动逻辑节点、不截断路径、不强制合并各角色资源。

## 6. 队列、计时与系统反馈

固定队列分别用「当前」「已行动」「倒地跳过」「下轮行动」及标记表达；不因受击或倒地动画把队列重新洗牌。公开主顶栏放当前行动者与冻结/有效倒计时；姓名过长仍用两行或已定义可识别简称。

| 状态 | 反馈文案 | 说明 |
|---|---|---|
| 决策中 | 「决策时间 …秒」 | 计时读规则状态 |
| 手动暂停 | 「已暂停 · 保留…秒」 | 明确继续按钮只在教师 |
| 绘本/编辑/历史 | 「已暂停 · …」 | 叠加原因，关闭不解除手动暂停 |
| 全员倒地 | 「全员倒地 · 等待教师处理」 | 无惩罚与自动重置 |
| 怪物行动 | 「怪物行动中」 | 不占学生决策时间 |
| 空资料 | 「暂无绘本，选择本地PPTX」 | 教师提示 |
| 加载 | 「正在读取本地资料…」 | 不伪装网络进度 |
| 导入失败 | 「导入未完成：…；原资料保留」 | 教师看具体报告，公开不露私有文件名 |
| 保存失败 | 「本次操作未提交；请重试或检查存储空间」 | 状态须由引擎确认原子性，不画成半成功 |
| 恢复存档 | 「已恢复 · 暂停中」 | 等教师继续 |
| 公开屏断连 | 「公开屏未连接」 | 教师状态；重连构造公开快照 |

## 7. 结果、回放与降低动态效果

普通伤害分别列盾吸收和生命减少；自然20加明确「自然20 · 全部目标战败」与原骰子结果；治疗、救援、奖励、掉落和结束同列于一次提交。包含多目标的结果容器逐目标列出，Teacher可查看更多，公开保持结果摘要与必要对象名可读。历史中显示操作来源、对象、实际变化、原骰子及完整回退范围；回放不再次滚动随机数字。

按钮120–180ms，面板200–250ms，资源300–450ms，骰子/自然20主要效果600–900ms。降低动态效果时：移除位移与粒子、立即显示完整结果，保留文字/边框状态。动画既不触发 GameEngine.apply，也不恢复计时、推进队列或判定战斗结束。
