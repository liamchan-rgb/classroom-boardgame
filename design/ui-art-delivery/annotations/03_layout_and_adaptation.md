# 布局、尺寸与长姓名适配

设计坐标用于交接，不是 App 固定屏幕尺寸。教师基准为1366×1024逻辑点；PNG为2倍2732×2048。公开基准为1920×1080与1440×1080设计单位。窗口、安全区域、外接屏分辨率由原生环境实际测量。

右栏三个职业技能保持在一屏入口；背包或技能详情内部滚动时执行、取消、结束回合仍固定可达。常用动作触区至少44×44，主要执行高52–56。材料、编辑、历史是独立教师视图，打开时按规则叠加暂停原因。

## 4. 长姓名与队列

| 场景 | 演示数据 | 判定 |
|---|---|---|
| 12汉字 | 晨曦森林守护者小队长安然 | 教师最多2行17；公开最多2行28，完整可读 |
| 24英文字符 | AlexandriaWinterbrookJoy | 允许在明确分段处换行；不改变真实姓名 |
| 主持人 | 林老师 | 名字与「主持人」各有区域 |
| 队列短称 | 安然、Alex、小禾、星星、阿乐、小满、老师 | 序号 + 短称能对应完整卡片；短称不写回角色数据 |

英文连续字符串使用显式展示断点「AlexandriaWi / nterbrookJoy」或字符换行；不要让默认单词换行导致整条超出卡边。公开队列空间有限时用序号与短称；当前行动者主区域及玩家卡仍展示完整名字。两角色短称相同须加角色序号或可区分后缀，不按职业缩写替代人的身份。

名字、倒地/主持人/行动中徽章和队伍标签优先级高于装饰头像。不要用省略号隐藏Teacher唯一完整姓名入口；公开缩写仅限已能通过完整卡对应的队列。

## 5. 同节点多人、多怪物

地图采用人物聚合气泡、数量与类别分组。教师点击展开当前节点已知名单；公开显示已知数量与行动者焦点，完整玩家资源仍在底卡。连接道路应穿到节点边缘且可读，人物不盖住可用路径。未知节点标记不为保留空间而换成实际怪物头像。

地图缩放移动只改变视图；节点ID、道路关系、规则距离、实例位置不变。插画背景可裁切或减装饰，节点和道路不得被裁掉。像素风头像使用等比缩放与清晰采样，UI文字保持系统矢量抗锯齿。

## 6. 本轮补充的公开绘本状态条检查

绘本后续整页使用本地静态页等比完整显示，允许留白，不裁切PPT正文。七角色公开状态可采用两行信息卡，须保留姓名、生命/最大生命、盾、金币、积分、队伍；不显示AP。绘本和状态条分别布局，不为塞满状态条把页面字体缩小到不能读。备注只在Teacher独立滚动，备注滚动、输入光标与编辑菜单不进入公开场景。

本轮另交public_storybook_16x9/4x3占位绘本页，检查7角色六字段与AP隐藏、等比页面区域。未交实际PPTX，教师绘本页和备注滚动仍需后续原生验收。
