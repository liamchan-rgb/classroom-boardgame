# 规则边界与双画面信息权限

交付版本：2026-10-12，第一轮设计。A「晨光森林」、B「晴空学园」均为可调整的视觉提案。本文不修改 GameCore，也不表示原生页面已实现。原需求、阶段1资料与 `initial-content.json` 是规则和数值依据；实际运行读取本局模板快照与已提交状态。

## 1. 本轮职责

本轮交教师战斗页、16:9 与 4:3 公开战斗页、风格小样、组件状态及接入说明。头像仅提供冒险者和捣蛋史莱姆少量方向样稿；其余职业/怪物仍按既有 ID 待制作。18 物品、完整地图装饰、商店、绘本与后台整页属于后续批次。预留这些模块的状态说明不等于扩展首轮功能，也不要求开发提前实现。

大型面板采用原生 iOS 毛玻璃材质；小按钮与徽章可用液态玻璃或实色。HD 像素风只影响插画、头像与装饰。姓名、资源、道路、节点、合法路径与目标均为独立界面元素，不烘焙进插画，不用像素坐标替代节点距离。

## 2. 游戏规则在 UI 中的含义

| 规则 | 界面必须怎样表达 | 禁止的视觉暗示 |
|---|---|---|
| 移动沿道路，每条道路 1 AP；射程按最短路径道路数 | 标明选择路径、实际道路数与费用；同节点距离 0 | 用插画上的直线距离、格子或障碍决定费用 |
| 战斗使用现有地图与玩家位置 | 战斗保持原节点/道路；行动焦点只改变镜头与标记 | 切入独立竞技场、把所有玩家传送到中心 |
| 普攻 AP1；职业技能按模板成本、射程、次数与阶段 | 按钮显示费用、射程、剩余次数、不可用原因 | 只画一个无条件「施法」按钮 |
| 普通药水 AP1、射程1；战斗只用个人背包 | 选择可用个人道具与合法对象 | 战斗直接从队伍仓库拿物或正常换装 |
| 救援 AP2 + 个人复活石1 + 同节点倒地队友 | 缺任一条件就不可执行；成功后显示恢复量、下轮资格 | 用普通治疗救起倒地者，或救援者与对象不在同地点 |
| AP补充是补足基础值 | 状态读实际 AP；奖励显示实际变化 | 每轮把基础 AP 当作追加值、把储存 AP 转给他人 |
| 手动结束保留剩余 AP；超时归0 | 按钮提示保留；超时结果展示实际 AP 清零 | 两者使用相同「清空行动点」提示 |
| 护盾取新旧较高值 | 盾与生命分开；盾变化由已结算差额显示 | 把护盾叠加，或把生命+护盾合成无区分的一条 |
| 倒地清盾与临时增益，其余资源保留 | 生命0、护盾0、倒地字样；金币/积分仍可见 | 倒地自动扣分、金币或删除背包 |
| 生命治疗不超过上限，普通治疗不复活 | 标注实际恢复值，触顶不显示虚假加值 | 按技能面额播放治疗数字而非结算差额 |
| 当前行动者与奖励对象独立 | 行动中徽章与奖励勾选并存；发奖对象标题明确 | 发奖选择使当前回合切换 |
| 固定队列与下轮资格 | 新加入、救援后显示「第…轮可行动」；倒地跳过 | 动画结束自行重排队列或赋予本轮额外行动 |
| 暂停原因叠加 | 显示冻结剩余时间；返回游戏保留手动暂停 | 离开绘本/历史后无条件自动继续 |

## 4. 一次结果，一次展示

仅伤害 D20 的原始点数20触发自然20；18+2、先攻20、治疗20均不能用秒杀表现。群攻只掷一次，共用该骰子。自然20无视盾令全部合法目标生命0，倒地/战败清盾。不要在盾吸收动画中先演算另一套普通伤害。

一次提交必须包含：行动费用、技能次数、原骰子、每个目标实际生命/盾变化、倒地/战败、施法者附带治疗/盾/增益、逐怪物实际掉落、积分、队列和阶段变化。显示完成与否不影响规则；重放、跳过、减弱动画均读同一结果。

自然20群攻演示独立采用龙骑士 `dragonFlame`：AP2，1D20+6，自疗6/获得6盾/伤害+2持续2轮；三目标为史莱姆、石像守卫、遗迹魔龙，击杀分1+1+5。实际演示只显示已选定的掉落，绝不根据模板概率临时抽取。玩家 `dragonFlame` 与怪物 `monsterDragonFlame` 是两个 ID；怪物龙焰没有玩家的自疗和盾。

最后敌人战败仍须先完成附带效果、掉落和积分，再显示回探索；战斗结束清临时战斗增益，保留实际生命、盾、AP与资源。多目标掉落逐怪物、逐项独立，可能多件或没有，属于最后击杀者。公开不显示概率。若教师后台将怪物生命改到0而没有指定归属，不能擅自给当前行动者击杀奖励。

## 5. 信息权限

| 信息 | 教师游戏/绘本/后台 | 公开战斗 | 公开绘本 |
|---|---|---|---|
| 姓名、当前/最大生命、护盾、金币、积分、队伍、主持人 | 是 | 是 | 是 |
| AP | 是 | 是 | 否 |
| 当前轮、行动者、队列、决策计时/暂停 | 是 | 是 | 可显示暂停摘要，不添加AP |
| 已揭示节点/道路、已公开单位 | 是 | 是 | 绘本正文之外不强制呈现地图 |
| 奖励对象勾选、预设奖励、未提交目标/路径 | 是 | 否 | 否 |
| 已提交奖励的实际对象/变化 | 是 | 可作结果 | 可作简短反馈 |
| 未揭示怪物、Boss、奖励内容、掉落概率、背包与编辑 | 是 | 否 | 否 |
| 备注、台词、教师输入、调试、导入报告、回退预览 | 是 | 否 | 否 |

未知节点仅显示中性轮廓与「未探索」，`kind = nil`；不用Boss头像、宝箱轮廓、地图光效或提前日志提示内容。未到达的相邻目的地只公开位置/轮廓，内容仍未知。教师私有地图信息可在教师详情中查看，不能顺带投到公开结果区。

公开绘本必须完整保留七角色六类信息：姓名、生命/最大生命、护盾、金币、积分、队伍，主持人标记和倒地状态可叠加。AP字段从公开绘本显示模型中移除；备注从公开模型中排除，而非靠遮盖或透明度隐藏。

## 6. 证据范围

教师反馈 v0.7 与规则示例真机无问题；资料记录38项规则计算和6项绘本核心验证通过。此轮设计不是 App 测试，不据此宣称新布局、最远观看距离、所有复杂 PPTX 或正式PVE已验证。完整规则与真机接入由开发对话负责；设计演示数据仅用于排版和状态检查，不是存档、可执行规则或内容替换。
