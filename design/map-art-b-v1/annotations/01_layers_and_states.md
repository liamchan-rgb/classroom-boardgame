# 分层、状态与交互

层序：低对比地面 → 通用装饰 → 已知道路 → 地点插画／统一未知轮廓 → UI状态标记 → 单位汇总与文字。

| 文件 | 含义与限制 |
|---|---|
| node_start/combat/boss/reward/empty | 已揭示的原类型；无怪物模板、数量或规则数值 |
| node_unknown | 所有未知类型共用；不随隐藏类别改变造型／色彩／比例；问号由App画 |
| node_state_current | 当前位置：指针＋实线圈；不代替行动者／奖励对象标记 |
| node_state_path | 教师规划路径：虚线圈＋箭头；未提交选择不公开 |
| node_state_enemy | 已揭示、仍有活敌人：交叉；不表示道路不可通行 |
| node_state_claimed | 实际奖励事件已完成：勾标；不重新发奖 |
| node_state_crowded | 数量徽章底座；数字由App生成 |
| node_state_target | 教师合法目标：四角框；不公开未提交意图 |
| fog_unknown | 中性视觉层；隐藏插画根本不加载，不能靠透明覆盖保密 |

叠加时current外圈、path次外圈、target内框；claimed与crowded分置左下／右下，避免覆盖。可由App重绘矢量或移动徽章底座，不重复绘制地点主体。多个角色与怪物汇总为数量并使用原对象列表，避免地图姓名覆盖道路。

road_normal为实际已公开道路；road_planned为教师规划；road_plan_unavailable只表示规划动作因实际条件不可执行。保留正常道路并就地说明AP不足等校验原因，绝非锁门、障碍或道路禁行；道路仍统一通行／成本1，射程与移动规则不变。

选择、查看不扣AP、不掷骰、不重置时间。公开端不显示教师奖励选择、未提交目标／路径、后台备注或未知内容。行动者与奖励对象独立，可叠加；地图标记不取代倒地、下轮资格等已通过组件。

本批不新增结算动画：自然20、伤害、自疗、护盾、掉落、积分、救援仅显示已提交结果。切地图、绘本或编辑保留暂停原因及剩余时间。公开状态条按本轮用户要求不显示AP；本批无资源条，也不沿用旧公开AP文字。
