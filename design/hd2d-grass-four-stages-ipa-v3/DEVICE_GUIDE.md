# IPA安装与查看

下载本轮`GrassHD2D-v0.3-unsigned.ipa`，通过已有SideStore流程个人签名安装。它是独立草原小样，不是正式课堂App升级包；包内不包含个人证书或预置签名。

系统名称GrassHD2D，版本0.3(3)，iPad横屏、最低iPadOS17。进入即为推荐的暖阳草原效果。

- 左上仅玩家名字；右上依次移动演示、光照切换、地图总览、设置。
- 太阳按钮循环原始素材/暖阳草原/地形光影；设置中可单独关闭或调节效果。
- 单指拖动，双指缩放；设置中的跟随人物配合移动按钮观察脚点与投影。
- 设置切换16:9、4:3；可一键恢复推荐参数。系统减少动态效果会停用环境微动。

本轮不提供中间截图审核结果。请实际安装后判断阳光方向、暗部层次、草地密度和空间感，以及拖动/移动时的流畅度；真机视觉和性能验收尚未完成。
