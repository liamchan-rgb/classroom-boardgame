## 视觉变化

- 近景暗树影与柔焦边缘、中景清晰站位地面、远景低对比山线/学院/水面，强化尺度差、光照与前后关系。角色保持清晰，接地影/当前行动者光圈单独由显示组件绘制。
- 探索占满主区；战斗区与地图扣除间隔后的宽度为7:3，开启详情仍保持此比例。7玩家与3怪物完整保留，角色血条常驻，精确数值通过标题/无障碍和公开详情查询，不铺大段数值卡。
- 顶栏只有当前全名与轮次/计时；底栏保留队伍标记、金币/积分与黄色行动力菱形。技能/物品只留短名、图标、物品数量，完整原定义放卡片上方毛玻璃浮窗。怪物回合收起技能和玩家资源底栏，保留完整混合轨道。

## 资产范围与限制

新增两张无文字环境原图，PNG字节保留；HTML使用它们作为单张非语义环境底图。尚未交付实际独立前/中/后景透明层，当前景深主要来自底图构图、光照和环境边缘柔焦；不声称已经实现可独立视差的HD-2D渲染。分层生产计划见[尺寸/动画/接入说明](annotations/layout-depth-motion.md)。

复用13张v7全身角色/节点/道具PNG及v4两张方向精灵sheet，字节一致。原有冒险者移动pilot与精细战斗全身人物的像素尺度尚不一致；本稿用于验证位置和流程，最终地图人物还需按新环境统一尺度，其他职业真实多方向肢体帧仍缺。未使用裁头头像冒充完整角色。

场景远处学院/山崖/水面均为无规则语义的装饰，不代表已揭示节点，不新增道路、地形费、障碍或奖励。公开未知节点只画问号，未揭示道路不画；探索隐藏怪物。角色不因为环境插画中的石头或水面而改变真实nodeID/射程。

原生毛玻璃/液态玻璃仍需Material/glassEffect接入；本HTML仅材质近似，不冒称已验证iOS、电视远距或性能。[后台光标联动文档](../player-battle-cursor-link-handoff-v1/cursor-popover-linkage.md)继续生效，教师私有待执行动作与公开查看保持分离。

浏览器检查见[evidence](evidence/browser-checks.json)，恢复存档见ARCHIVE_INDEX.md。旧版本、素材、ZIP和标签全部保留。
