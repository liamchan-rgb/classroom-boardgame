# 玩家战斗详情浮窗 × 教师后台光标联动

用户要求：考虑战斗详情展开和后台光标的联动，并记入技术文档。本文件规定接入行为；不代表App已完成这些行为。材质、锚点和7:3布局沿用v7的`annotations/layout-and-popover.md`。

## 联动入口与公开边界

教师iPad战斗操作区应有与公开端卡片一一对应的「公开查看」技能/物品卡。后台光标悬停或键盘焦点进入这些卡片，公开端对应卡片亮起，并在该卡片上方展开毛玻璃详情浮窗；点击该卡片固定查看。教师端同步标明「正在公开查看」，避免误认为已选定执行动作。触屏没有悬停时，以点击查看/关闭提供同等操作。

联动按语义ID映射，不传鼠标坐标，也不把后台光标画到电视上。教师端与电视端尺寸、分页、比例不同，电视端用自身卡片bounds定位浮窗与箭头。后台光标移入教师本地详情时，本地浮窗和来源卡组成同一查看区域，保持临时浮窗；离开整个区域后才关闭。

教师私有操作区的技能选择、目标、移动路径、奖励勾选、编辑器和教学笔记不触发公开浮窗。当前已有`choose/target/tapNode/selectPlayer/toggleReward`等操作接口不能顺带修改公开查看状态。若现有技能按钮同时负责执行规划，应另设清楚标注的查看区域/控件，不能让一个点击同时固定查看和提交动作。公开查看也不读取私有待执行选择推断展示项。

## 显示状态与传递建议

当前`PublicPlayFrame`已有`currentDetails`、`itemPage`和地图相机字段，尚无本文件建议的浮窗状态；`cameraFocusID`是地图角色焦点，不能复用为技能查看ID。`PVEAppSession.publish()`是当前生成并发送公开frame的接口，`PVEPublicView`是显示端；后续开发在显示层接入，本文不修改它们。

建议新增独立、可选的公开展示DTO，以下均为拟议字段：

| 字段 | 含义与约束 |
| --- | --- |
| `publicInspect` | nil为关闭；只传已公开技能/物品的查看状态 |
| `actorID` | 必须匹配当前`currentDetails.unitID` |
| `entryKind` + `entryID` | skill/item及稳定目录ID，不能用卡片序号或名称代替 |
| `mode` | transient临时 / pinned固定 |
| `contextToken` | 本场战斗与本次行动机会的显示上下文；同一角色再次行动也必须更新 |
| `inspectSequence` | 查看事件的单调序号，防旧事件覆盖新事件 |

这些状态由教师端展示协调器统一管理，随公开frame原子发布；不写入GameArchive、操作历史或随机数状态。上下文token是显示会话标识，不要求新增规则字段。应用恢复、重新连接外屏时默认关闭；不能重放旧悬停或旧固定状态。未知DTO字段/旧客户端应降级为关闭详情，保持基本战斗展示。

公开详情只从当前frame的`currentDetails.skills/items`查询，保留原费用、完整效果、次数/数量、适用条件和不可用原因。不可执行的卡片仍可查看原因；查看不调用执行接口、不扣资源、不选目标、不切回合、不暂停或重置计时。已有publicFrame投影计算按原实现运行，浮窗事件不另外触发规则预演。

## 状态转换

| 教师端事件 | 公开卡片与浮窗 |
| --- | --- |
| 光标进入/键盘聚焦公开查看卡A | 无固定项时临时展开A；只存在一个浮窗 |
| 从A快速移到B | 更新为B；取消A的延迟关闭任务 |
| 光标移入A的本地详情区域 | 保持A，便于阅读长内容与使用关闭键 |
| 离开整个查看区域/焦点移出 | 临时项关闭；固定项保持 |
| 点击查看A | 固定A；同项再次点击关闭，点击另一项切换并固定 |
| 固定A后悬停B | 保持A；点击B才替换，避免阅读中跳窗 |
| 关闭、作用域内Esc、查看区域外点击 | 清空浮窗；外部点击后原控件事件仍可继续，不当作提交行动 |
| 行动机会变化、怪物回合、战斗结束、切局、恢复 | 清空状态及所有待处理事件，卡片恢复默认 |
| 打开笔记/编辑器/绘本或教师端停用 | 关闭公开详情，禁用该查看作用域，使用原有模态/暂停策略 |
| 数量或可用性更新但上下文未改变 | 用新公开数据刷新；条目已不存在则关闭 |

建议悬停稳定约100ms展开、离开约150ms关闭以减少抖动；点击与键盘焦点立即响应。延迟只是显示层调度，所有任务携带contextToken、entryID和sequence；任务完成前复核仍有效。旧卡mouseleave不能关闭新卡；战斗切换后旧任务不能重开浮窗。已提交动作不需要为展开详情再播放表现或重复提交。

物品跨页查看：后台公开查看卡所属页和inspect状态一起发布；电视先显示正确页并完成锚点布局再展开，不向不存在的卡片画箭头。手动翻页到不含当前项的页面时关闭浮窗；关闭后保留当前页。同名技能/物品以及排序变化均用ID匹配。

## 焦点、布局与动画

查看焦点与执行规划焦点分开。系统输入框、笔记TextEditor、导入/编辑sheet聚焦时，键盘事件留在该作用域；不能触发战斗卡片查看或吞掉输入。Esc先关闭当前查看浮窗，不同时取消私有行动计划。关闭按钮支持44pt触区、VoiceOver名称与焦点返回来源卡；VoiceOver进入「公开查看」控件等同焦点查看，避免连续重复播报。

公开端卡片高亮与浮窗来自同一inspect状态，不分别维护两份选中值。原生使用Material浮窗，以当前端卡片锚定；regular Material模块、常规Liquid Glass按钮、小控件纯色方向保持。详情展开后预留展示区，战斗/地图宽度持续7:3，连续回合轨道、血条、黄色行动力菱形和当前资源区均可见。关闭恢复默认舞台高度；换项在同一浮窗内替换内容和锚点，避免两窗重叠。

建议开合/换锚点180–220ms短过渡，角色脚底/血条随容器统一布局，卡片位置尽量稳定，防止展开造成光标被动离开卡片。减少动态时直接终态；减少透明度走系统实色回退。4:3需单独核对原生安全区、键盘/外屏和长详情位置，当前v7只有16:9三态样稿，未声称新4:3已验收。

## 接入验收清单（待开发执行）

1. 鼠标/触控板悬停、键盘聚焦、触屏点击分别能操作公开查看；电视无触控也能完整查看和关闭。
2. 六个示例卡与实际多页物品按ID正确联动；同名、重新排序、翻页不会展示错项；箭头始终指向本端所选卡。
3. 快速A→B、离开再进入、固定后悬停、关闭后延迟回调均只有一个正确浮窗；外屏重连默认关闭。
4. 行动者切换、同一角色下一次行动、怪物回合、战斗结束/恢复与延迟任务竞态不会重开旧详情。
5. 私有技能/目标/路径/奖励/笔记变化不改变公开查看；公开DTO不携带私有选择或未揭示信息。
6. 仅执行查看序列前后，AP、HP、金币、物品、轮次、历史、随机状态与操作收据不因查看变化；按正常墙钟推进的计时不暂停、不重置。
7. 禁用卡仍可读完整不可用原因；固定期间数量/费用/可用性来自最新公开投影，不缓存旧值。
8. 原生16:9与4:3、长内容、VoiceOver、减少动态/透明度验证通过；战斗/地图7:3，轨道、血条和资源无遮挡。

本轮检查为文档与现有接口的只读对照，未改App、未运行联动功能测试；上述验收需接入后完成。
