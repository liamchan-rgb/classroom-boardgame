# 美术与UI设计交接

第一轮视觉方向与交付标准，配合原生App阶段2开始使用。

- [美术与UI设计标准](美术与UI设计标准_v1.md)：双画面、尺寸、组件状态、素材、验收与接入时机。
- [新对话启动提示词](新对话启动提示词.md)：复制到新设计对话，并附交接包。
- `design-tokens_v1.json`：建议颜色、尺寸、字体、触摸与动效令牌。
- `asset-manifest_v1.json`：已有模板ID与计划制作的34项资产绑定；尚未生成美术。

设计对话交预览与独立资产，开发对话在SwiftUI接入。设计修改限制在独立分支/工作区的design目录，避免同时修改游戏与构建代码。
