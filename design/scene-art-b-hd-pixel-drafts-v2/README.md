# B晴空学园 · HD像素场景草稿v2

最新用户意见覆盖v1的精细手绘方向：希望HD像素、类似八方旅人的场景观感。本版改用明显的像素轮廓、材质色阶与前中后景层次，并保留明亮湖蓝/奶油白/春绿/少量金色。

[四景原图](previews/hd_pixel_scene_concepts.png)：左上学园庭院，右上林间空地，左下湖畔石桥，右下古迹花园。像素建筑、树冠、石路、水面配柔和光照；构图中部留给角色。仅参考HD-2D空间/光照原则，原创场景，不复刻原作资产或3D渲染。

本轮为生成式概念草稿：局部景深与像素尺度尚未经过生产级统一，不宣称精确固定像素网格或真实低分辨率原稿放大。原PNG字节保留，未用后处理像素滤镜替代场景重做。四景对照用于审美确认，不是运行sprite sheet或四套已拆层资源；角色合成、7玩家+3怪物阵位、血条可读性与真机效果待验证。

后续制作要求：统一基础像素尺度；像素实体采用nearest采样，光晕独立叠加；保留不模糊的角色/地面；拆分远景、中景、地面与前景透明层。湖畔护栏及古迹花盆等构图需再检查站位，不新增障碍、地形费、节点或奖励规则。两比例需各自构图与安全区校核，当前只交2×2对照草稿，无16:9/4:3成品UI。
