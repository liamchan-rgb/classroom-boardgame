## 交付状态与真实边界

本小样待用户审美确认；不能因做完就记为达到理想效果。地面重复感、光照自然度、人物风格一致性和模块边缘仍需对照原图继续审核。没有批量扩展雪地、火山或战斗素材。

原图集的均等格假设不可靠：自然景物初稿/地点初稿出现跨格轮廓，保留在sources/candidates；修正后的资源仍采用**测量后的独立sourceRect**寻址，不盲用512×512格裁切。见[module清单](module-manifest.json)。本轮保留生成PNG原字节，通过渲染器按矩形采样，未用背景色抠图。

浏览器显示样板验证了本地素材、组装和移动终态，未在SwiftUI/App接入，未做原生玻璃或真机性能验证。参考最新main `576afd41403b3bfd0108ae5685a7a3e870c3281e`的公开图/相机/已提交移动接口；没有合并或修改App。细节见[技术交接](annotations/rendering-and-acceptance.md)、[证据](evidence/browser-checks.json)。

世界坐标使用原5节点参考，只绘公开1→2、2→3边；未知节点只画问号，不画未知地点/道路。种子17/30是独立装饰随机数，不调用规则随机流。植被、泥土、围栏、光影不新增障碍、费用、奖励或伤害。

控件沿用此前原生毛玻璃/液态玻璃要求；理想图中的棕色按钮不自动覆盖该约定。图片沟通继续使用真实绝对路径Markdown文件链接，见../image-communication-guide-v1/README.md。只写独立设计分支的新版本目录，旧文件/素材/ZIP/标签保留。存档见ARCHIVE_INDEX.md。
