# 随机地图的HD像素模块组装套件v5

用户指出地图随机生成，整幅风景底图与粗线道路不适合；附件只参考地点、道路和人物的位置关系。本轮用模块重新组织大地图，继续已确认的B晴空学园HD像素风格。新模块/道路/构图待审，没有修改App、地图生成器或规则。

## 交付资源

- 三张1536×1024 RGBA模块图集：[草地](assets/atlases/grass_modules.png)、[雪地](assets/atlases/snow_modules.png)、[火山](assets/atlases/volcano_modules.png)。每套6种，共18个可寻址模块：地面纹理、植被、岩丘、营地、哨塔、遗迹。
- [模块清单](module-manifest.json)给atlas、源矩形、512×512单格、脚底锚点和用途；原图保持字节不变，程序按sourceRect采样，不把整张图集画入地图。
- 每环境3种道路标准件（直路/弯路/分叉），共9份透明PNG及9份SVG，位于assets/roads。另有[道路材质参数](road-style-tokens.json)和实际图边的曲线/纹理绘制源码。标准件用于道路视觉交接，主地图按真实端点绘制，不强迫随机图迁就固定拼图。
- 4张已有全身人物PNG字节复用；8张两比例组装预览、可离线运行的Canvas示意、组装/alpha证据、[技术交接](annotations/assembly-and-binding.md)。

地面纹理未通过严格相对边像素相等的无缝验证，采用256px贴片、224px间隔、约18px淡边重叠；不能直接当作无缝瓦片硬拼。当前每环境只有一种地面源纹理、两种装饰主体，重复感仍需后续变体扩充。图集含半透明接地边，需保留alpha；不要按RGB底色抠图。

## 人物、地点与道路

地点插画放在节点旁的空地，节点圆标保持真实坐标；插画通过显示偏移避开现有道路，不挪节点。人物脚底锚在道路中心或节点圆标；地面、图标、人物共用同一个等比相机。移动与绘路使用同一三次曲线，图边数量、移动费用和触发点仍由原规则决定。

草地是带泥土/石粒的浅土路，雪地是压实雪径，火山是风化岩路；不是纯色拓扑连线。未知节点只画问号，不放地点插画，未揭示道路不进入绘图/避让数据。没有新增地形阻挡、岩浆伤害、冰雪减速或遗迹奖励。完整地点类型皮肤绑定仍需开发按现有公开nodeVisual核对，不能从装饰推断规则。

本轮只处理大地图组装。上一轮战斗场景、7:3界面、详情浮窗与后台光标文档保持有效；旧风景图可保留作战斗/概念参考，旧文件、ZIP、标签均未覆盖。原生随机地图接入、所有地图肢体帧、动态分层与真机验收仍待后续完成。恢复存档见ARCHIVE_INDEX.md。
