# 原生v0.7：安装、覆盖更新与真机验收

设备：2021款12.9英寸iPad Pro、iPadOS27、实体键盘和无线镜像电视。本样例验证能力，尚非完整桌游。

v0.6已用Xcode27.0与iOS27 SDK编译成功，6项核心测试通过，IPA已校验。[构建记录](https://github.com/liamchan-rgb/classroom-boardgame/actions/runs/38222596815)与[产物](https://github.com/liamchan-rgb/classroom-boardgame/actions/runs/38222596815/artifacts/11735060890)保留至2026-10-15。

v0.5安装失败的原因是Apple拒绝中文appIdName。v0.6已将安装名称改为ClassroomProbe；教师已安装并反馈各功能正常，同意进入阶段1。v0.7新增规则示例与资料页，使用同一账号覆盖更新。以下完整流程供首次初始化及后续验证使用。

## 云端生成IPA

1. 将源码放进**私有GitHub仓库**，保留隐藏目录 `.github/` 和整个 `native/`。仓库根目录必须能看到 `native/ClassroomProbe.xcodeproj`。
2. 确认标准Actions免费配额可用，将额外付费预算保持为零。不要改用大型runner，无需Apple开发者会员。
3. 打开 **Actions → Build personal iPad app → Run workflow**。工作流只手动运行，检查SDK27，测试核心，再编译App。
4. 全部成功后下载 **ClassroomStage1-build** 产物，解压到iPad“文件”。其中应有 `ClassroomStage1-unsigned.ipa`、SHA256、构建信息、源码提交号及日志；产物保留3天。
5. 失败时查看具体失败步骤，日志仍会保留；没有成功编译则不会生成IPA。`xcode-27`是官方预览runner标签，其调度权限与可用性需实际账号确认，不换成缺少SDK27的旧镜像冒充完成。

**未个人签名IPA无法直接点击安装。** 它要交给SideStore／AltStore以免费账号签名。

## 首次安装与续签

首选 [SideStore官方安装流程](https://docs.sidestore.io/docs/installation/install)，从 [原项目发布页](https://github.com/SideStore/SideStore/releases) 获取当时官方推荐版本。2026-10-12查到0.7.0-alpha用于修复旧版本Apple登录问题，实际以官方最新说明为准。

1. 教师已确认有电脑，操作系统待确认。当前官方使用iloader，通过USB和免费Apple ID安装SideStore；具体链接与操作见 [首次安装_SideStore.md](首次安装_SideStore.md)。
2. 按官方说明配置LocalDevVPN。Apple登录、双重认证在教师自己操作的工具中完成，不上传密码、验证码或配对文件到仓库。
3. 在SideStore选择云端IPA，完成个人签名和安装；若系统要求，按界面启用开发者模式或信任个人开发者。
4. App名称为 **ClassroomProbe**，教师界面版本为 **阶段1 v0.7**。
5. 免费签名有效期7天。到期前用所需网络和LocalDevVPN刷新SideStore自身及本App，记录有效期是否延长，重新启动验证。
6. 验证一次覆盖更新：继续用同一账号和安装工具安装新版本，检查金币、页码和存档保留。删除App会影响本地数据，不用删除方式更新。

免费个人账号通常最多同时安装3个此类App，SideStore占一个。无需开发者订阅，不使用TestFlight。周期签名需联网，可课前完成；课堂运行单独验证离线能力。

备选 [AltStore Classic](https://github.com/altstoreio/AltStore) 的 [Remote AltServer](https://faq.altstore.io/altstore-classic/remote-altservers) 仍需首次电脑配对。完全只有iPad时，设备侧初始化候选尚未验证，不将安装条件写成已满足。

## 无线独立画面与隐私

只使用合成假备注。系统菜单、崩溃和外屏切换尚未验证，先不输入真实课堂台词。

1. 启动App，连接电视无线镜像。教师端“公开场景1”仅表示场景连接，仍须观察电视实际内容。
2. 电视应显示绿色 **英语课堂 · 公开画面**，以及7角色生命、护盾、金币、积分和队伍；iPad显示教师按钮。
3. 点 **加载内置测试PPTX**。页序应为图文测试页、空备注测试页、长备注测试页，图文页有内嵌图片。
4. 目视确认独立显示后开启教师备注：第1页含 `PRIVATE-FIXTURE-8642`，第2页为空，第3页3200字符。电视不应出现备注或该标记。
5. 测试编辑备注、文件导入／导出、报告、控制中心、后台、锁屏，随后恢复；断开重连投屏。逐项记录电视最后画面、是否回到镜像、备注是否隐藏。
6. 若电视出现教师控制台或备注，关闭备注并记录触发步骤，隐私验收判失败。

检测到断连或进入后台时App尝试隐藏备注并暂停，但源码不能保证系统切换过程中绝不泄露，必须取得真机证据。

## 离线绘本、键盘、暂停与备份

保留iPad与电视局域网，断开互联网后操作；这与签名刷新需联网不矛盾。

1. 从“文件”导入小型测试PPTX，核对逐页报告、比例、图文位置、页序和字体。基础渲染对母版、主题等有限制，详见报告。
2. 数字键1—7选择角色，G发10金币，长按G不应连发。备注编辑时G、空格和数字只作为输入，不触发游戏。
3. 空格开始计时，剩余约17秒暂停，等待后恢复应从原值继续。备注和文件选择独立暂停，关闭其中一个不能解除其他暂停原因。计时到零后先重置30秒。
4. 编辑备注、改变金币和页码，保存并导出备份。备份含教师备注，只放在教师管理的位置，不属于公开屏数据。
5. 重新启动App，检查绘本和状态恢复，计时保持暂停。导入备份，核对绘本、备注、金币、页码和剩余秒数。
6. 导入损坏PPTX或非法备份，确认明确报错且当前绘本和状态保留；不使用唯一存档进行破坏测试。

保存位置为本App的Application Support。备份包含原PPTX及备注修改，移走原PPTX后仍应能恢复。阶段0限制：1—60页、PPTX最多32 MiB、备份最多48 MiB、单页备注最多40000字符。阶段1GameCore已实现正式游戏数据与完整回退，现阶段通过独立示例验证；正式游戏存档界面后续接入。
