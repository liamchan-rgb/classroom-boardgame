# 题库格式标准（地图随机事件 · 选择题）

创建新地图时，可以在「随机地图与新行程」里点 **导入题库**，选择一个 `.txt` 或 `.json` 文件。
导入后，地图上的「路边失物」随机事件会变成 **答题事件**：小队到达后，题目投到电视上，老师在 iPad 上点全班选出的选项，
答对的成员获得该题金币（默认 10）和 1 积分，答错或跳过不扣分。每个事件点只答一次。不导入题库则保持原来的随机事件。

题库随存档保存，读档后题目不变；同一张图上各事件点按顺序取题（起始题由地图种子决定），题目不够时循环使用。

## 一、纯文本格式（推荐，可直接从 Word 复制后另存为 UTF-8 的 .txt）

- 每道题一段，**题与题之间空一行**。
- 第一行是题目，可带题号：`1.`、`1、`、`第1题` 都会被自动去掉；题目可以写多行，写在选项之前即可。
- 选项每行一个，以 **A–F** 开头，后面跟 `.` `．` `、` `)` `）` `:` `：` 之一，例如 `A. 根`、`B、叶`、`C) 茎`。至少 2 项，最多 6 项，必须从 A 依次排列。
- `答案：B`（必填，写选项字母；冒号中英文均可，也可写 `正确答案：`）。
- `金币：15`（可选，0–200，默认 10）。
- `解析：……`（可选，答完后在电视上显示）。
- 以 `#` 或 `//` 开头的行是注释，会被忽略。
- 判断题写成两个选项：`A. 对`、`B. 错`。

示例见 [question-bank-sample.txt](question-bank-sample.txt)：

```
1. 光合作用主要在植物的哪个部位进行？
A. 根
B. 叶
C. 茎
D. 花
答案：B
金币：15
解析：叶片中的叶绿体是进行光合作用的场所。

2. 3 × 7 = ?
A. 18
B. 21
C. 24
答案：B
```

## 二、JSON 格式（适合用表格或脚本批量生成）

```json
{
  "questions": [
    {
      "prompt": "光合作用主要在植物的哪个部位进行？",
      "options": ["根", "叶", "茎", "花"],
      "answer": "B",
      "coins": 15,
      "explanation": "叶片中的叶绿体是进行光合作用的场所。"
    }
  ]
}
```

- `answer` 可以写字母 `"B"`，也可以写从 0 开始的序号 `1`。
- `coins`、`explanation` 可省略；也可以直接给一个题目数组 `[ {...}, {...} ]`。

## 三、限制

| 项目 | 限制 |
|---|---|
| 文件 | UTF-8 编码，不超过 2 MB |
| 题目数量 | 1–500 题 |
| 题目文字 | 不超过 600 字 |
| 选项 | 2–6 个，每个不超过 200 字 |
| 金币 | 0–200 |

格式有误时导入会提示是第几题、哪一行，原来的设置不受影响。
