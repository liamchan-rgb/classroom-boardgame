# 题库格式标准（地图答题事件 · 选择 / 闪卡 / 填空 / 阅读）

> 想让大语言模型帮忙出题：用 [question-bank-llm-prompt.md](question-bank-llm-prompt.md) 里的提示词。

创建新地图时，可以在「随机地图与新行程」里点 **导入题库**，选择一个 `.txt` 或 `.json` 文件。
导入后，地图上的「路边失物」随机事件会变成 **答题点**。小队到达后**每位同学各答一题**（选中谁、谁答）：
题目和倒计时投到电视上，学生口头说答案，老师在 iPad / Mac 上**点学生说的那个答案**（不在选项里就点「不会」或在「其他」里输入）。
提交后电视揭晓答案并发奖励；同一答题点里在场的队友都答过后，这个点才结束。

- **奖励按难度（所有题都一样，包括闪卡练习、全班题、个人挑战和地图答题点）**：答对（多空/多小题要全对）发 ★ 10 金币 +1 行动 +1 积分、★★ 20 金币 +1 行动 +2 积分、★★★ 30 金币 +1 行动 +3 积分；“行动”是给该同学所在队伍的移动条加 1 步（满了不再加）。答错或部分对不发；全班题答错可由老师发“参与奖”金币。个人限时题超时不发。没写难度的题按 ★；题库里的 `金币：` 不再改变奖励；不再掉落物品。
- **限时**：默认 ★ 60 秒、★★ 90 秒、★★★ 120 秒，可用 `时间：` 单独设置。
- **难度与题型绑定**：★ 基础、★★ 提高只出**单词（短语）闪卡**——这些是本节课要掌握的高频词，学生报告会单独列出；★★★ 挑战才出句子类题目：**句子闪卡（看中文说英文整句，即口头造句）、填空、选择、阅读**。
- **编辑题目**：题库面板每门课的「编辑题目」（或顶栏课程菜单「编辑题目…」）打开整门课的题目编辑器：搜索、按题型筛选，改闪卡正反面（可点词典释义）、选择题选项与正确答案、填空候选词、阅读文章与小题、难度、标签、解析，可删题（会先确认）、新增闪卡。打开着的行程里这道题原位更新，已作答的记录保留。
- **修改作答**：题目本身在题库里改；作答记录在报告窗口「修改作答」里改——按同学或关键字找到某条作答，可改为答对、改为答错或删掉（删除前确认）。关掉面板后报告按改过的记录重新生成；已经发出的金币和积分不变，需要时用 GM 调整。
- **一套题库**：一门课的所有题（闪卡、选择、填空、阅读）是同一套，个人挑战、全班题、闪卡练习和地图答题点都从里面出，不再分“专属题 / 公用题”。旧题库里的 `份：` 和 `对象：` 行仍能导入，但会被忽略。App 自带示例题库，题库为空时在「题库」里点「示例题库」即可。
- **出题方式（老师在后台选，个人挑战和全班题共用，记在本机）**：
  - **全随机**：每答完一题，从这门课的全部题里随机抽下一题。
  - **按难度随机**：选 ★ / ★★ / ★★★，只从这一档里随机抽（没标难度的算 ★）。
  - **老师点选**：按难度分标签（全部 / ★ / ★★ / ★★★）列出所有题，点 👁 可先预览整题（选项与正确答案），点题目即出这一题。
  - 随机抽题时**先出“未考察”和“有错”的题**：个人挑战按这位同学（没答过的、最近一次答错的），全班题按全班（没人答过的、有同学最近一次答错的）；这些都出完了才重复其他题。老师点选的题单也有“未考察”“有错”两个标签。重复出现的**选择题、填空题会打乱选项顺序**（记录与报告仍按原题判分）。
- **怎么出题（快捷键都可在「快捷键」窗口改）**：
  - **个人挑战 Q**：Q 打开挑战设置，选同学（1–7）、出题方式和时长（1/2/3/5 分钟或 ± 半分钟），回车开始。电视顶部显示倒计时和成绩；学生不选题，按出题方式出题：随机模式答完自动出下一题，老师点选模式每题从题单里点。学生作答你录入（闪卡按 **D 对 / C 错**，其他题 A–H 选项、0 不会），选好即揭晓并按难度发奖（无快答加成）；空格换一题；等下一题时 1/2/3 按该难度出、R 全随机出。时间到即停，正在答的那题不计，Esc 提前结束。
  - **全班题 ⇧Q**：按出题方式出一道题给全班（老师点选时先弹出题单）。面板里 1–7 勾选回答的同学（可多选）、A–H 选他们说的答案、回车揭晓并发奖——答对的发「答对」金币并记答对，答错的发参与奖并记答错；空格换一题（发送前），Esc 只揭晓不发奖。
  - **闪卡练习 K**（顶栏「闪卡」固定入口）：这门课的全部闪卡，个人或全班（A 切换），可选卡、顺序/乱序，按 **D 对 / C 错** 记录后自动下一张。只记录不发奖励，错词进报告。
  - 地图答题点按题库顺序给到达的同学出题（全班没出过的优先）。
- **按课程管理**：题库存在 App 里，与游戏进度无关。每导入一个文件就是一门课，**课程名就是文件名**（如 `爱丽丝第二章题库`），同名文件再导入会更新这门课；可一次选多个文件导入。顶栏的课程按钮显示当前课程，点开列出所有课程手动切换（主按钮打开“题库”面板，可改名、删除、载入示例）。答题挑战、全班题、闪卡练习和地图答题点只出**当前课程**的题；新开的行程自动用当前课程。行程只保存用过的题和作答记录（奖励、报告），切换课程不会丢失已有作答。
- **错词**：闪卡、填空的空格、以及标签含「单词 / 词汇」的题都算单词题。报告第一页列出全班「易错单词」（错几次/问几次、最常说成什么），每人一页的「错词本」列出他答错的单词、意思和说成了什么；报告窗口的「复制错词」可把全班与每人的错词复制成文字。
- **答题报告**：每次作答都随存档保存。顶栏「报告」（快捷键 R）可查看并导出 **PDF** 或 **PNG**，窗口上方切换两种：**学生报告**（每位同学一页，给家长看：课程名、答对率与一句话总结、★/★★/★★★ 各档答对数、“本节课需要掌握的高频词”按 还要练 / 进步了 / 已掌握 / 未记录到闪卡练习中的重点词 分组并标星级、挑战失败的句子，每句标题型）和**完整报告**（全班总览、闪卡总表、每人两页含作答记录，给老师看）。

## 一、纯文本格式（推荐，可直接从 Word 复制后另存为 UTF-8 的 .txt）

- 每道题一段，**题与题之间空一行**。
- 第一行是题目，可带题号：`1.`、`1、`、`第1题` 都会被自动去掉；题目可以写多行，写在选项之前即可。
- 选项每行一个，以 **A–F** 开头，后面跟 `.` `．` `、` `)` `）` `:` `：` 之一，例如 `A. 根`、`B、叶`、`C) 茎`。至少 2 项，最多 6 项，必须从 A 依次排列。
- `答案：B`（必填，写选项字母；冒号中英文均可，也可写 `正确答案：`）。
- `金币：15`（可选，0–200，默认 10）。
- `解析：……`（可选，答完后在电视上显示）。
- 以 `#` 或 `//` 开头的行是注释，会被忽略。
- 判断题写成两个选项：`A. 对`、`B. 错`。

示例见 [question-bank-sample.txt](question-bank-sample.txt)：

```
1. 光合作用主要在植物的哪个部位进行？
A. 根
B. 叶
C. 茎
D. 花
答案：B
金币：15
解析：叶片中的叶绿体是进行光合作用的场所。

2. 3 × 7 = ?
A. 18
B. 21
C. 24
答案：B
```

### 题型与可选字段（纯文本）

每道题都可以加这几行（顺序随意）：

- `类型：选择 / 闪卡 / 填空 / 阅读`（不写时自动判断：有 `正面：` 是闪卡、有 `文章：` 是阅读、题目里有 `{{ }}` 是填空，其余是选择题）
- `难度：1`～`3`，也可写 `简单 / 中等 / 困难` 或 `★★`
- `时间：90`（秒），也可写 `1:30`、`2分钟`
- `标签：过去式, 动词`（知识点，报告里按它统计，最多 8 个）

**闪卡**：电视展示正面，学生说背面，老师在后台对照答案直接判对错（不出选项，`干扰：` 可不写）。

```
类型：闪卡
难度：1
正面：apple
背面：苹果
干扰：梨, 香蕉
```

`干扰：` 可省略——会自动借用题库里其他闪卡的背面凑够 4 个选项，方便老师点学生说成了哪个。

**填空**：用 `{{正确答案|常见错答|…}}` 标出空格，第一个是正确答案，后面是给老师点的常见错答（可不写）。电视上空格显示为 ①②…。

```
Tom {{went|goed|go}} to school and {{saw|seed}} a cat.
难度：2
标签：过去式
```

**阅读**：`文章：` 后面可以写多行（不能有空行），每个小题以 `问：` 开头，下面跟选项和 `答案：`。

```
类型：阅读
难度：3
文章：Tom has a red ball.
He plays with it in the park every day.
问：What color is the ball?
A. red
B. blue
答案：A
问：Where does Tom play?
A. at school
B. in the park
答案：B
```

## 二、JSON 格式（适合用表格或脚本批量生成）

```json
{
  "questions": [
    {
      "prompt": "光合作用主要在植物的哪个部位进行？",
      "options": ["根", "叶", "茎", "花"],
      "answer": "B",
      "coins": 15,
      "explanation": "叶片中的叶绿体是进行光合作用的场所。"
    }
  ]
}
```

- `answer` 可以写字母 `"B"`，也可以写从 0 开始的序号 `1`。
- `coins`、`explanation` 可省略；也可以直接给一个题目数组 `[ {...}, {...} ]`。
- 每题都可加 `"type"`（`choice` / `flashcard` / `fill` / `reading`，也可写中文）、`"difficulty"`（1–3 或 "简单/中等/困难"）、`"seconds"`、`"tags"`。
- 闪卡：`{"type":"flashcard","front":"apple","back":"苹果","distractors":["梨"]}`
- 填空：`{"type":"fill","prompt":"Tom {{went|goed}} home."}`
- 阅读：`{"type":"reading","passage":"…","questions":[{"prompt":"…","options":["…","…"],"answer":"A"}]}`

## 三、限制

| 项目 | 限制 |
|---|---|
| 文件 | UTF-8 编码，不超过 2 MB |
| 题目数量 | 1–2000 题（可多次导入追加） |
| 题目文字 | 不超过 1200 字；阅读文章不超过 4000 字 |
| 选项 | 选择题 2–6 个；闪卡/填空每空最多 6 个（含正确答案）；每个不超过 200 字 |
| 小题 | 填空最多 12 个空，阅读最多 12 个小题 |
| 金币 | 0–500 |
| 时间 | 10–600 秒 |

格式有误时导入会提示是第几题、哪一行，原来的设置不受影响。
