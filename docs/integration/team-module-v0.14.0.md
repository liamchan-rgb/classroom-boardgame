# v0.14.0/build19 · 六名学生组队与主持人独立席位

依据仓库docs/课堂桌游_需求设计_v1.md §1.2/3.1/3.2/8.1/9.1/10.1。当前用户已将移动改为与战斗AP独立的距离移动条，覆盖原需求§5.4；本轮按当前规则实现分队移动上限为该队最大AP平均×50，分队余额独立，不乘人数，不与战斗AP互扣。

## 可操作入口与范围

教师「管理 → 随机地图与新行程」设置1—6名学生，逐人姓名和职业；默认同队。新行程人数由新档确定，继续旧档保持原人数/姓名/职业。旧双人格式可读，不重投地图或重置资产。教师「管理 → 队伍与仓库」可新建队伍、调整成员、拆队、改队名、保存分组；合并按钮一次提交成员与两队仓库，保留清空的旧队用于历史追溯。成员换队只改teamID，个人装备/背包/金币/生命/AP/技能次数保留，旧队仓库留原队。队伍积分实时求当前成员总分。

同队金币与个人背包物品可互转、存仓、取仓，只在探索可用，无AP消耗、无同节点要求；装备已穿戴则不在背包中，须先卸下。跨队普通转移禁止；教师须显式启用“教师跨队调拨”，同样限探索并记录独立历史事件。操作由原GameEngine一次提交，带回执/历史，可原子撤销，保存失败不留半边状态。行走中的成员/分队调整先完成当前道路目的地；正在动作演出时禁止编辑，战斗静止阶段允许调整队伍但仓库禁用。

地图仅同队同位置存活成员同行；不同队不被拖走、只扣当前队的距离余额，购买只用当前队金币；选择另一队恢复其余额。战斗仍沿用原规则让场上玩家进入原队列，同队关系由原规则判断，不新增第二引擎。地图角色/步态数组、血条/行囊/消耗品目标、战斗演员/血条/目标命中改动态人数；为P1—P7提供站位，使用原六方向/八方向已认可资源，不新画动作。P3—P7独立外观尚缺，复用现有资源并用编号/姓名区分，资源缺失只标注。

## 预留老师下场接口

ClassroomGameBackend.joinTeacher(name:classID:team:role:)仅教师角色可用：探索、无道路游标、无已结算行程时增加host=true的p7。最多6名非host学生+1名host；不能再加入第二个主持人。host沿用职业、装备、资源、计分和战斗规则，不取消教师后台权限，不进入学生计数。当前不提供启用主持人的UI；未来调用接口后重装同一会话渲染器以刷新人数。公开端不能调用该接口，也不能调整组队/仓库。

## 验证与边界

新增12项专项覆盖1—6人往返存档/人数非法、六人队列、老师独立名额与权限、换队字段/RNG不变、共享仓库守恒/合并/撤销、旧仓库保留、跨队/透支/战斗拦截、持久化失败回滚、不同队不跟随、分队余额与AP独立。此前317项规则/后台测试在Linux零失败，新12项与完整设备Release结果以team-module-v0.14.0-build.json为准。

教师一屏工具栏、原技能卡点击/悬停、960×540/30Hz目标与电视原生60Hz目标保持。无App/模拟器/实机运行，仅纯规则测试、源码审计、离线资源/布局示意及设备Release归档；6人站位、标签密度、实际性能和电视隐私由用户安装复核。怪物数量沿用现有已确认地点配置，不自动改怪物属性或强度。新增独立角色美术不在本轮制作。

后两项仍为绘本小型人物状态区≤画面10%；教师在绘本页发AP/金币。原需求绘本条不含AP已被用户最新明确要求覆盖；本轮不顺带实现。
