## 使用入口与筛选

教师游戏右上“管理 → 人物档案 / 行程槽 / 历史 / 老师参战”，教师绘本“存档与历史”，均沿用原私有窗口。

行程页可搜索标题、原槽号、成员姓名/ID、队伍名、地图种子/游戏ID；多个词按同时匹配，忽略大小写与音调符号。状态分为探索中、战斗中、已结算；可叠加1—7人数量过滤。排序为最近保存、最早保存或原槽号，同时间按原槽号稳定排序。显示匹配/已保存数量和清除筛选；读取/导出/覆盖始终使用原槽号，不用排序后的行号。空槽仍独立提供新建保存，坏槽独立报错且不受筛选隐藏，筛选无匹配也不会阻止保存或隐藏损坏文件。

历史页可按战斗、移动与地点、资源与物品、组队与老师、人物外观、地点配置等类别，叠加涉及人物/怪物和关键字过滤，支持升/降序。搜索操作名称、当前记录前后成员名字/ID、原始序号、事件描述与骰值。即使攻击/结束行动没有单位字段变化或事件，仍按命令收集参与者；改名保留新旧姓名可查，改队名关联原队成员。索引后台整理并保留不可变搜索字段，关键词变化只过滤索引，不重读JSON或重建整份历史；先显示50条，按需再显示50条。

**筛选只影响列表，不改变历史。** 展开仍查看原回执和骰值/数值变化，回退保持原记录ID/序号，并撤回其后所有原始操作，包括被筛选或分页隐藏的记录。提示及确认均明确这一点；回退继续先备份、恢复规则/RNG/队列/移动检查点并暂停。查询不写档、不发奖励、不推进骰子或AI，不把“列表第1行”误当原第1条操作。
