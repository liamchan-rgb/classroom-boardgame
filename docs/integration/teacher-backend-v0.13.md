# v0.13：移除旧游戏，教师后台控制当前 Meadow demo

按用户 2026-11-07 的更正，删除原桌游 PVE 游戏页面、规则示例页、旧地图/战斗公开页和 v0.12 简化动画适配。没有旧游戏回退开关。保留课堂 PPT 导入、页面、备注、备份和 iPadOS27 独立公开场景。

## 两端的职责

教师后台负责随机地图参数、分类数量/滑块/种子、职业设置、新行程/续档、道路选点、人物选择、地点编辑、奖励/服务配置、移动购买或补满、个人资源调整、发奖、队伍、行囊装备操作、战斗技能/目标/悬停和回合操作。后台选点模式不会把编辑选择、对话框或编辑提示投放到游戏中。

公开端使用 experiment Build95 的完整真实组件：Metal 大地图/光影/建筑/八向人物；战斗使用 MeadowBattlePreviewView + MeadowPartyBattleView + MeadowPartyStageView 的既有布局、动作、骰子、受击/死亡与技能资源。探索显示地图，选战斗地点可展示怪物预览；教师打开行囊时显示只读玩家行囊/装备摘要，关闭后返回地图。发生真实战斗时自动显示现有战斗预览，公开端无编辑、补满、重置、结束回合等管理按钮。绘本只公开页面，备注不进入公开视图。

## 单一后台与投放宿主

ClassroomGameBackend 持有唯一 MeadowCampaignSession 和唯一 PartyEncounter；地图生成、行走推进和角色命令经过后台。MeadowTeacherCoordinator 在后台驱动唯一决策计时与怪物AI；公开战斗视图不再自行开第二份计时或AI，不创建训练局覆盖正式战斗。命中回调提交后台已确认事务，仍沿用现有一次结算/一次掷骰机制。

只有一个实际 GameViewController 渲染器：未连接外屏时放入教师的只读预览，连接外屏后移到独立公开窗口。后台控制地图是操作工具；不会截图镜像整个教师界面，也不会创建第二个游戏会话。绘本/教师暂停保留同一会话，后台设置和所有私有弹窗有独立 teacher presenter；即使渲染器在外屏，编辑弹窗也只在教师窗口出现。

ClassroomRole 在后台命令入口拒绝 publicDisplay 的生成、安装、编辑、发奖、补满、移动和投放选择请求；公开表面枚举只有 waiting/exploration/inventory/encounter/battle/book/results，没有编辑或权限界面。实际公开 UIView 不挂载管理按钮并禁用游戏输入，战斗按钮的操作由教师后台调用，悬停仍驱动相同骰子/压暗预览。
