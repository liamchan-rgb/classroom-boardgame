# Meadow × 课堂桌游：公开画面试接 v0.12

本轮将 experiment 已有 Meadow 美术接到 classroom-boardgame 原生 demo。源码基于 main 1e9100c4c18364ea64b3ec974fe957ba4ef42f6f；美术来自 experiment 175c7dfc4a68e62cb9693da8d837b77081619a6b，逐文件校验见 Resources/MeadowArt/provenance.json。

## 教师端与公开端

| 内容 | 教师操作端 | 公开展示端 |
|---|---|---|
| 地图 | 原布局、全部地点供教师操作 | 只读公开节点/道路，未知地点继续隐藏详情 |
| 战斗 | 原选人/目标/技能/行动面板、资源编辑 | Meadow 舞台、当前参战角色、生命条、独立行动点与结算动画 |
| 发奖、撤销、记录 | 保留原入口 | 不提供操作，不接收私有选择状态 |
| 备注 | 仍由教师端管理 | 不进入公开 DTO |
| 绘本/PPT | 原控制与备注隔离 | 原绘本页与公开角色条，不叠战斗特效 |
| 回退 | “公开端使用 Meadow 画面”关闭 | 立即恢复原 PVEPublicView |

进入“PVE课堂”后，顶部增加公开画面切换与“预览公开画面”。预览在教师设备中显示同一个公开数据源，返回即恢复控制；电视/外接屏继续通过原 externalNonInteractive 场景显示 PublicSurface。无需外接屏也能查看试接效果。

## 规则和显示时序

只有原 PVEAppSession / GameEngine 结算、掷骰和保存。新视图仅接收 PublicPlayFrame，既不能发送命令也不持有引擎。PresentationLedger 为真实 receipt 记录经过 publicSnapshot 过滤的 before、技能 ID 和实际资源变化；它们只用于显示，不改变存档结构。命中 .46 秒显示伤害/死亡，恢复/新护盾 .72 秒后生效；混合技能分别处理。排队动画保持前一条结果，恢复/撤销/暂停沿用原 ledger 清理，不重新执行历史。移动使用已提交路径，抵达后进入战斗。战斗只取 queueIDs，排除附近非参战单位。

地图规则仍采用桌游 demo 的道路/AP 规则。没有把 Meadow 的距离移动条、随机地图或单人训练引擎替换进来，避免两个规则源。教师的私有技能悬停不会向公开端广播。

## 素材复用与明确缺口

复用已认可的正向/斜向完整行走 atlas、蓝衣近战注册分层与原动作 JSON、六种怪物待机/攻击/受击/死亡 atlas、森林背景、符文斩/龙焰/护盾/治疗等现有特效。治疗按实际恢复量 <4 / 4..<8 / >=8 分档。攻击附颜色匹配粒子与局部环境补光；资源不重画、不重新切人物手臂。

本次默认双人 adventurer/spellblade 使用蓝衣通用近战外观。ranger/dragonKnight 等其余职业暂保留原 demo 角色美术，不误套持剑动作；新怪物模版也回退原美术。专属职业/装备造型绑定、远程完整挂载动作以及逐技能精确动作时间轴标为后续缺口。不能把这个试接版称为全部 Meadow 玩法或全部职业美术已迁移。

## 验证与交付

纯 Swift 规则及桥接测试、生成项目一致性、原生 Swift 编译与通用 iOS 设备 Release 归档；IPA 检查 arm64、版本、资源、CRC、经典 ZIP2.0 和权限。遵照用户要求不启动 App、模拟器或实机。离线 GIF 为资源/时间轴合成预览，不冒充 UIKit 或外接屏运行截图。外接屏连接、实际屏幕布局、PPT 切换与操作体验由用户安装后验收。

后两步：①根据教师端/公开端实机反馈调整比例、字重与信息密度；②逐职业补装备/远程动作绑定和逐技能时间轴，缺失美术仅标注。

## v0.12.1 自查修正

离线逐帧检查发现治疗高亮会覆盖接敌中的角色。治疗叠层改至人物背后，附带恢复 .72 秒后开始；符文斩前半段凝聚、命中时进入峰值，龙焰仍从命中起播放。上一版源码、IPA 和归档保留，最终交付使用 v0.12.1/build13。
