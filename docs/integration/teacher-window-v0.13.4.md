# v0.13.4/build18 · 教师游戏窗口一屏操作

用户要求游戏相关教师按钮放入游戏窗口，无须上下翻页；技能必须与画面已有技能卡合并。本轮删除教师后台整页ScrollView、独立battleControls技能网格、镜头箭头和画外按钮。教师窗口固定为44pt管理栏、48pt阶段操作栏、可自适应留边的真实游戏画面、28pt单行状态栏。全屏复用同一窗口，常用按钮始终在一屏内。低频新行程/恢复/保存/资源/发奖/队伍/路线/节点编辑收进管理菜单，地图拖动捏合保持。

战斗直接命中原MeadowPartyBattleView技能卡，坐标先按ClassroomCanvas消除教师窗口留边，再沿实际UIView转换到同一公开源技能卡与角色；不创建第二套技能、第二个战斗或新的随机数。鼠标悬停原卡触发原骰子预览，点击直接走已有教师权限/合法性验证。点原角色/血条选择目标，窗口栏另有紧凑目标菜单、道具菜单、暂停/继续、结束行动。现有公开技能卡在课堂模式按可见数量均分宽度，不预留已移除道具按钮空间，不需横向滚动。

操作栏是教师宿主的兄弟视图，不属于GameViewController捕获内容；公开电视仍无权限按钮/教师备注/输入权限。源公开View的技能/目标回调继续禁止，新的命中查询和操作仅经requireTeacher接口调用。拖动和技能点击分别判定，不会在战斗拖动时移动地图或误发技能。

本轮保持960×540/30Hz教师回传与电视原生60Hz目标。完整规则测试、设备Release归档和包检以teacher-window-v0.13.4-build.json成功记录为准。仅做静态布局/离线示意审核，不启动App/模拟器/实机，实际点击、投屏隔离和屏幕布局由用户安装复核。正常GIF明确是离线界面结构示意，不称UIKit截图。缺美术只登记。

后两项仍为绘本生命/AP/金币状态总占画面≤10%；教师绘本页发放AP/金币，本轮未实施。
