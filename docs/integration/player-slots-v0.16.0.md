# v0.16.0/build21：人物档案、行程槽、历史回退与老师参战

本轮完成用户已授权的后两项，并加入独立人物档案与地图行程槽。原教师一屏界面、同一正式引擎、30Hz教师镜像目标和公开端权限隔离保持。

## 使用入口

游戏右上“管理 → 人物档案 / 行程槽 / 历史 / 老师参战”，绘本教师页“存档与历史”。四个分页均为教师私有表单，既不附在公开渲染器，也不进入电视捕获。没有当前行程时仍能先制作/读取人物档案。

- **人物档案12槽**：只保存人物名与外观（现有林间/行旅款式，以及跟随实际护甲、蓝衣、皮甲、符文甲装扮）。读取到编辑区不会立即修改当前角色，需另点“应用到当前角色”。应用只改姓名/外观，不带入职业、金币、背包、装备、战斗数值或地图进度。衣装装扮不提供装备属性，武器仍跟随实际装备。新行程各学生行内有“读取人物档案”，可逐人选不同槽；教师P7也能保存/读取档案。
- **完整行程8槽**：保存原MeadowCampaignSave，包括地图、成员、背包、各队移动条、道路游标、镜头、战斗队列、随机数游标和操作记录。独立标题、时间、人数与节点数；覆盖有确认，读档前先备份当前工作行程。战斗槽读取后手动暂停，教师确认后继续，不重复触发奖励/掷骰。原campaign-v1自动工作档与旧两人存档继续兼容，新地图不会清空手动槽。
- **自动备份**：读行程、历史回退和开始新行程覆盖工作档前，以唯一文件名保存当前完整行程。行程页提供最近20份恢复入口，旧文件保留。验证/写入失败不安装新行程，不删除错误文件。槽位范围固定，人物与行程文件命名空间分离；单个坏槽独立显示错误，其余槽继续可读。
- **历史回退**：倒序列出操作，展开查看命令、骰值与成员HP/AP/金币变化；“回退到此条之后”保留所选这一条，删除其后记录。规则状态、RNG、队列恢复到所选记录，新记录还保存对应道路/移动条/镜头/操作成员检查点。回退前留备份，回退后暂停，重新安装同一来源的一套行程与渲染器，不另建训练引擎。旧记录无移动检查点则停止道路游标并保守保留当前余额，不凭空补满。
- **老师参战UI**：选姓名、职业、队伍，使用人物编辑区现有装扮；仅探索、未结算、无道路游标时加入独立P7席位，最多6学生+1老师。与原正式个人AP/组队/背包/战斗队列/绘本状态/GM共用一个引擎，不占学生席位，不重置旧六人；已加入时不显示重复加入按钮。

## 数据与兼容

新增GameUnit.appearance为可选字段，旧JSON缺省nil；addHost历史命令新增可选appearance仍能读取旧记录。Profile只含formatVersion/name/appearance。Slots目录位于原Application Support/ClassroomMeadow下，profile-N.json与campaign-N.json分开，Recovery保存完整备份。原formatVersion1保持，新增可选checkpoints；记录ID唯一并对应现有历史。玩家配置经教师角色检查，事务验证后写入。档案应用/加入老师均单笔命令，失败不部分提交、不消费随机状态。

地图按当前出现的角色装扮按需加载已认可图集，复用原AuthoredLocomotion；只缓存当前成员所需变体，换装备预载后再提交，避免一人护甲准备清除其他人的纹理。衣装同步战斗挂载与背包缩略图。**独立男女体型、发型/脸/染色编辑美术尚缺，只标记，未新增素材；战斗基础体型沿用现有骨架。**
