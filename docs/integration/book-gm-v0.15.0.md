## 玩家GM

教师游戏窗口右上角GM、教师绘本页GM窗口通向同一私有UIKit宿主，兼容全屏。可选择任意学生或已加入老师角色，编辑姓名、当前HP/护盾/AP/金币/积分、基础最大HP/基础AP/基础AP上限/伤害加成/射程加成、临时增伤数值与剩余轮数、技能已用次数，以及目录内每种个人背包物品的绝对数量（0移除，可搜索）。各数字输入始终保留字段标签。

基础值与装备加成区分；穿戴槽、身份、职业、队伍、位置和仓库不会被此表单改动。提高上限不自动补满HP/AP/地图移动条；降低上限须同时将当前资源调到合法范围。设倒地清除护盾/增伤，复活沿用下轮行动资格；仍在道路游标中的成员设倒地须先抵达建筑节点。GM只在动作演出空闲时提交，合法性与整数范围由原引擎检查。技能次数仅在明确保存或清零按钮保存时变化，不因打开窗口刷新。

GM保存是单次原子命令，成功才刷新公开状态；错误保留草稿，关闭未保存内容不写入。提供撤销最近一次GM/绘本发放入口，只允许最后一条确为相应教师操作时使用，不能越过后续战斗/奖励/组队操作；需教师权限。撤销恢复该次玩家数据，同时保留当前绘本/编辑/手动暂停等显示状态；当前行动者未变时保留剩余计时，不把历史绘本暂停带回游戏。地图移动条作为独立距离账本不会因提升上限自动补满。
