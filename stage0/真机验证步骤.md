# 阶段0：iPad最小样例测试

本样例只验证候选路线；目前未编译，遇到编译错误应先记录原文并修复。它还不是可以上课使用的桌游。

## 先确认条件

已确认设备：2021款12.9英寸iPad Pro、iPadOS27、原生支持无线镜像的电视。本阶段PPTX由开发方制作，不需上传大文件，不测试Windows/Linux产品端。

当前App Store的Swift Playground是免费工具，要求iPadOS18.0及以上；商店列出的4.7使用iOS26 SDK。候选v0.2尝试通过系统公开Objective-C方法调用27的新外屏注册接口，并检查类型、方法与签名。此桥接尚未编译／运行，不保证可用；若失败先记录错误，不直接判断电视不支持。

第一次下载安装 Swift Playground 需要联网；样例没有外部包依赖。完成下载后，本地编译、冷启动和运行能否断网执行仍需实测。运行时可保持与无线投屏设备的局域网连接，同时断开互联网；离线不等于切断投屏所需的无线连接。

## 导入与运行候选样例

1. 在iPad下载最新 `DisplayProbe_iPadOS27_v0.3.swiftpm.zip`，保存至“我的iPad”，点击解压；将新版保存到单独位置，保留旧项目作对照。
2. 打开解压后的 `DisplayProbe.swiftpm`，选择 Swift Playground。若“文件”中不能直接打开，从 Swift Playground 的文档浏览器打开该包；仍不能导入就记录文件打开方式和系统提示。
3. 点击“运行App”，使用独立运行界面，不用编辑器的预览小窗。若编译失败，提供完整错误文本；当前没有编译通过的证据。
4. 独立运行界面应出现“教师端 · 阶段0测试 v0.3”。此时台词保持隐藏。若仍看到next／export报错，先确认打开的是新版解压目录。
5. 从控制中心建立当前使用的无线投屏，再返回样例。查看教师屏上的注册状态、独立场景数量，并观察接收屏是否显示绿色“学生公开画面”，教师iPad是否仍显示控制界面。

如果公开屏只是镜像教师界面，记录“不通过：没有独立公开画面”，不要输入真实备注。样例通过场景角色数仅显示连接情况，不代表隐私验收已通过。

如果显示“注册失败”，记录完整原因；如果显示“已调用接口”但没有独立场景，记录两项情况。接口调用成功不等于公开画面建立成功，画面建立成功也不等于所有断连操作隐私通过。

## 逐项测试

| 操作 | 检查 |
|---|---|
| 外屏出现绿色公开页 | iPad显示教师控制页，两屏内容不同 |
| 显示／编辑假台词 | 只有iPad出现黄色台词区域；公开屏绝不出现PRIVATE-TEST-4731 |
| 按翻页与发金币按钮 | 两屏页码／金币同步，台词不进入公开页 |
| 点击继续，17秒附近暂停，等待后再继续 | 暂停期间不减秒；恢复从剩余值继续 |
| 手动暂停再编辑／关闭台词 | 仍保持手动暂停 |
| 按G、松开，再长按G | 第一次加10；长按仅加一次，不持续加金币 |
| 在台词输入框输入G | 正常输入文字，金币不增加；关闭台词后游戏键恢复 |
| 导出JSON至“我的iPad” | 文件存在；改变页码与金币后再导入，数据恢复并保持暂停 |
| 导入错误JSON | 给出错误，原页码／金币／时间保持不变 |
| 保存、关闭样例、恢复 | 保存状态可恢复；不立即继续倒计时 |
| 断开／重连投屏，打开控制中心、切换App、返回运行页 | 任何时刻是否出现假台词／教师后台都记录；出现即隐私不通过 |
| 保留局域网投屏，断开互联网并重开样例 | 本地运行、键盘、保存和导出可用；记录重开是否触发在线依赖 |
| 导入同一包的下一版本并再次运行 | 更新步骤可重复；记录是否覆盖文档、需要账号或有费用 |

本地JSON是阶段0的文件能力测试，不替代正式完整存档；假台词与三页文字测试不替代真实PPTX页面和备注导入。
